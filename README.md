# 🏏 IPL Ball-by-Ball Data Analysis | Gen AI + Kaggle

## 📌 Project Overview

This project presents a comprehensive analysis of the **Indian Premier League (IPL) Ball-by-Ball Dataset** using data sourced from **Kaggle** and enhanced with **Generative AI**.

The analysis explores 18 seasons of IPL data, covering deliveries, matches, teams, players, venues, batting performance, bowling performance, dismissals, extras, toss decisions, and match outcomes. The project combines data analysis with Generative AI to transform raw cricket data into meaningful insights and a structured analytical report.

---

## 🎯 Project Objectives

The main objectives of this project are to:

* Analyze IPL ball-by-ball data across multiple seasons
* Identify top-performing teams and players
* Analyze batting and bowling performance
* Study match wins and team performance
* Explore venue trends
* Analyze toss decisions and match strategies
* Examine dismissal patterns and extras
* Generate meaningful insights using Generative AI
* Create a professional and structured data analysis report

## 📈 Key Findings

* Mumbai Indians emerged as the leading team by total match wins.
* Virat Kohli ranked as the leading run scorer in the dataset.
* Yuzvendra Chahal ranked as the leading wicket taker.
* Teams showed a strong preference for fielding first after winning the toss.
* Caught dismissals were the most common method of dismissal.
* Wides were the most frequently recorded type of extra.
* IPL match volume increased over time as the tournament expanded.
